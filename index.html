IA · RAG

IndustrIA

Sistema de perguntas e respostas sobre manuais técnicos de manutenção industrial, com arquitetura RAG (Retrieval-Augmented Generation). Os manuais chegam organizados de formas diferentes, por isso o desafio é extrair e organizar o conteúdo de fontes distintas antes de o consultar.

Stack
Python · FastAPI · PostgreSQL · pgvector · LLM (Groq)
Contexto
Projeto pessoal e individual, feito para aprender embeddings. Ainda em evolução: a interface não está concluída, por isso não há demo.
Dados
2 manuais técnicos reais, escolhidos para manter o processamento rápido.
  1. Manuais em PDFextração e chunking
  2. Embeddingsall-MiniLM-L6-v2
  3. PostgreSQL + pgvectorpesquisa por similaridade de cosseno
  4. LLMgeração da resposta (Groq)
  5. API FastAPI

Automação industrial

Python CNC Modelling Controller

Software que construí de raiz, durante o estágio na OPTIMA, para controlar uma máquina de modelação 3D por pinos: os pinos sobem para moldar o objeto. O utilizador importa um ficheiro CAD, o software mostra o objeto numa grelha 3D e permite pôr a máquina a trabalhar, vendo tudo a acontecer em tempo real.

Stack
Python · GUI · trigonometria · geometria euclidiana
Contexto
Estágio curricular na OPTIMA (Grupo Tecmacal). O repositório é uma demonstração da lógica: partes específicas do hardware foram removidas por confidencialidade.
